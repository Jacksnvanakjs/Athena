我想做个监测基金额度数据的网站，要实现的功能如下：
一、数据源
1、见同一工作区的“额度数据来源.txt”，一共几支基金，然后每行左边是基金名字，右边是对应基金网址。
2、数据处理
基金网址页面上有以下2种限额状态，下面2种状态对应基金网站实际文字：
交易状态：限大额 (单日累计购买上限100.00元)
交易状态：暂停申购 (单日累计购买上限10.00元)
然后你抓取额度变化时，就是先看“暂停申购”还是“限大额”，如果是“暂停申购”，直接返回额度0.
如果是“限大额”，就返回“单日累计购买上限100.00元”里的数字“100.00”部分，但是每次数字可能不一样，记得根据实际数据来。

二、数据可视化
1、在交易日早上 9:00 和下午 6:00 各抓取一次基金额度数据，周末和中美节假日不用抓取，请求频率别太高，单次抓取关注的那几只就够，加上随机延迟。
2、抓取到的数据每次都必须存储，因为要做可视化图表展示。
3、凡是额度变化必须实时通知我，用Server酱 / PushPlus方案。HTTP接口发送消息到微信。检测到额度变化时，直接POST一条消息就行，用户手机端秒收。
4、如果抓取的基金里有1/3及以上额度发生变化，立即用表示“额度集体变化”意思的消息通知我，并附上额度前后对比。
